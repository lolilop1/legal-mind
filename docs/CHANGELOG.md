## 2026-09-10

### Модуль 3 — регионы
- Собрана база 85 регионов: `region/data/noise_laws.db`
- 5 итераций RAG: v1 → v2 → v3 → v4 → v3-hardcoded
- Yandex Search API + YandexGPT Pro + `host:` фильтр
- 81 из 85 автоматически, 12 hardcoded вручную

### Определение региона
- Regex: 26 паттернов на 85 регионов
- Embeddings: 85 векторов, Yandex Text Embeddings
- Гибрид: regex → fallback embeddings
- Двойной фильтр: скор > 0.35 + разрыв > 0.02
- Обогащение городов: у каждого региона 2–18 крупных городов

- Endpoint: `https://ai.api.cloud.yandex.net/v1`
- SDK: `openai` (Responses API)
- Экономия: 6× на каждом запросе
