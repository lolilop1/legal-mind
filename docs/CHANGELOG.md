## 2026-09-13 (Модуль 1: расширение норм по услугам — ст. 27-33)

### Добавлено
- configs/service.py: allowed_norms расширены до ст. 27, 28, 29,
  30, 31, 32, 33, 22 ЗоЗПП
- configs/service.py: demand_options «уплатить неустойку за нарушение
  срока» (3% за день, ст. 28) и «отказаться от услуги» (ст. 32)
- configs/service.py: llm_hints описывают 4 подтипа услуги, LLM
  выбирает нормы по фактам из описания
- pre_checks: _SERVICE_SUBTYPES — детект подтипа (нарушен срок /
  смета превышена / отказ / некачественная работа)

### Как работает
Юзер не выбирает подтип — система определяет по тексту:
- просрочка/опаздывают → ст. 27, 28 (неустойка 3%)
- смета/дороже/доплати → ст. 33
- передумал/отказываюсь → ст. 32
- халтура/дефект/отклеивается → ст. 29, 30

  некачество, подтип не для defect)
