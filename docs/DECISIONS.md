## 2026-09-12 — Умная шапка PDF

**Контекст:** всегда было «Директору X». Но продавцом может быть ИП,
самозанятый или физлицо. «Директору ИП Иванов» — бред.

**Решение:** `_format_addressee` определяет адресата по вводу:
- ООО/АО → «Директору X»
- ИП/самозанятый → «X» (как есть)
- ФИО 3 слова → «Гражданину/Гражданке <дат.>»
- 2 слова → pymorphy определяет роль (Ф/И или И/Ф)
- 1 слово = имя → «Гражданину/Гражданке X»
- Ники → «Продавцу X»

## 2026-09-11 — Legal Trace (этап 5)

**Контекст:** пользователь получает PDF, но не понимает, почему система
выбрала именно эту норму. Юридически это важно — норма должна быть объяснима.

**Решение:** цепочка «Факт → Квалификация → Норма → Источник».

Где показываем:
1. В карточке дела /case/... — блок «Как система пришла к норме»
2. В DNA — сохраняется в поле trace как JSON
3. В PDF — пока не показываем (место ограничено, добавим позже)

**Почему в карточке, а не в PDF:**
- PDF — короткий документ, там нет места для объяснений
- Карточка — цифровое дело, может содержать метаданные
- Пользователь может зайти и посмотреть в любой момент

**Что кладётся в trace:**
- fact — что сказал пользователь (обрезано до 120 символов)
- qualification — юридическая квалификация (из словаря модуля)
- norms — список применимых норм
- source — URL источника (для модуля 3 — из БД, для модуля 2 — федеральные)

## 2026-09-11 — Версионность (этап 6)

**Контекст:** PDF-документы генерируются по шаблонам и правилам,
которые со временем меняются. Через год невозможно понять,
по какой версии сгенерирован конкретный PDF.

**Решение:** три поля версий в каждом документе.

- engine_version — какой движок (uk-01, noise-01, consumer-defect-01)
- rules_date — версия правил (формат 2026.09 — год.месяц)
- template_version — версия шаблона (1.0, 1.1)

Где отображаются:
1. В PDF — серая строчка внизу, 8pt, цвет #787878
2. В карточке дела /case/... — блок «Версия документа»
3. В БД — сохраняются в таблице cases при создании

**Правило обновления версий:**
- engine_version — меняется при изменении логики модуля
- rules_date — меняется при обновлении норм (раз в квартал)
- template_version — меняется при правке PDF-шаблона

## 2026-09-11 — Confidence / UNKNOWN (этап 4)

**Контекст:** hard-check уже умеет отличать vague-описание от нормального,
но показывал просто «Документ не составлен» без объяснения что не так.

**Решение:** два новых понятия — pre-check отчёт и документ-заблокирован.

- Если is_blocked — показываем pre_check_blocked.html со списком

**Что считаем критичным:**
- Модуль 2 (УК): объект проблемы (уборка, лифт, крыша, отопление, вода)
- Модуль 3 (шум): вид шума + источник шума

**Что опционально:**
- Дата начала
- Регион (для модуля 3, если не определился из адреса)

## 2026-09-11 — Автодеплой через GitHub Actions (этап 8)

**Контекст:** ручной деплой (scp + ssh + chown + systemctl) занимает
5 команд и забывается.

**Решение:** GitHub Actions + SSH на VPS.

Как работает:
1. git push в main
2. GitHub запускает workflow
3. Workflow заходит по SSH на сервер
4. git fetch && git reset --hard origin/main
5. systemctl restart legal-mind
6. curl /health — проверка
7. При провале — задача помечается красным

**Альтернатива — deploy.ps1 локально.** Остаётся как резерв,
если GitHub Actions недоступен.

**Что важно:**
- Deploy Key сервера — read-only на репозиторий
- SSH_PRIVATE_KEY для GitHub Actions — отдельный ключ, не личный
- Хранится в GitHub Secrets

## 2026-09-11 — Форма сохраняет данные при ошибке

**Контекст:** тестеры жаловались — заполнил описание, ошибся в телефоне,
всё пропало.

**Решение:** сохранять данные формы в session при стопе и
восстанавливать при возврате.

**Механика:**
- При стопе → _save_form_to_session(request.form)

**Почему:** UX-катастрофа, если пользователь теряет текст.
Один раз простит, второй — уйдёт.

## 2026-09-10 — LLM не выбирает законы из памяти

**Контекст:** стандартный подход — «спросить у LLM, какая норма применима».

**Решение:** LLM только переписывает текст. Закон подставляет код
из фиксированного списка.

**Причины:**
- LLM галлюцинирует: придумывает несуществующие номера статей
- Мы это видели: ФЗ «О полиции» как норма о тишине (ошибка)
- Hard-check + фиксированный список норм = детерминированно

**Для модуля 2:** 3 федеральные нормы захардкожены в app.py.
**Для модуля 3:** закон читается из region/data/noise_laws.db по региону.

## 2026-09-10 — Определение региона: гибрид

**Контекст:** нужно понять регион из адреса пользователя
(«г. Москва, ул. Ленина, 15» → «Москва»).

**Решение:** два уровня.

1. Regex (26 паттернов на 85 регионов) — быстро, <1 мс
2. Embeddings (Yandex Text Embeddings, 85 векторов) — fallback

**Двойной фильтр для embeddings:**
- Скор топ-1 > 0.35
- Разрыв топ-1 / топ-2 > 0.02

**Обогащение городов:** у каждого региона список 2-18 крупных городов.
Без этого «Химки» не находились.

**Почему не Search Index AI Studio:** у объекта SearchIndex в SDK
yandex-ai-studio-sdk нет метода .search(). Отказались.

## 2026-09-10 — PDF: fpdf2 вместо reportlab

**Контекст:** первая версия PDF была на reportlab.

**Решение:** перешли на fpdf2.

**Причины:**
- reportlab кладёт шрифт без корректного ToUnicode CMap → текст
  из PDF не копируется
- fpdf2 встраивает шрифт правильно → копипаст работает
- Побочный баг fpdf2: после multi_cell(align="R") курсор X остаётся
  справа. Решение: обёртка _mc(), сбрасывающая X.
