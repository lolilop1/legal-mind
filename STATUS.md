## Что сделано

2. Entity check с границами слов.

4. Формат: «нарушают требования: 1. Закон...».
5. 12/12 API-кейсов.

### База 85 регионов

Пять итераций RAG:
- `v1-minimal` — YandexGPT Pro, 79/85, много ошибок.
- `v2-alice-pro` — Alice Pro, отказы (Крым, Севастополь, Татарстан).
- `v3-host-filtered` — Alice Pro + host:, 6/10.
- `v4-pro-host-filtered` — **финальная** (YandexGPT Pro + host:), 81/85.
- `v3-hardcoded` — 12 регионов с ручной проверкой (приоритет).

**Итог: 85/85.**

### Определение региона

1. **Regex** — 26 паттернов на 85 регионов, 26/26 тестов.
2. **Embeddings** — Yandex Text Embeddings, 85 векторов.
   - Двойной фильтр: скор > 0.35 + разрыв топ-1/топ-2 > 0.02.
   - Обогащение городов: 2–18 крупных городов на регион.
3. **Гибрид:** regex → fallback на embeddings.

## Ключевые решения

1. **Alice AI Flash** для нормализации — в 6 раз дешевле YandexGPT Pro.
2. **LLM не выбирает законы** — только переписывает текст.
3. **Гибридный регион** — regex + embeddings.
4. **Двойной фильтр эмбеддингов** — скор + разрыв.
5. **PDF на fpdf2** — ради копипаста.
6. **Склонение через pymorphy3**, не petrovich.
7. **CASE хранится (вариант А)** — DNA + текст + PDF + файлы.
8. **UUID + номер CASE** — без регистрации и SMS.

## Известные ограничения

- **Нет домена и HTTPS.** Работает по IP `201.24.49.121`.
- **CASE не хранится.** PDF генерируется в памяти и отдаётся.
- **Промпт не защищён от продвинутых adversarial-атак.** Базовые отбиты.
- **Эмбеддинги неидеальны** — модель путает близкие регионы, двойной
  фильтр решает в 99%.
