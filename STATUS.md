## Что сделано

### Модульность
Переехали с плоской структуры на модульную. 10 файлов тестов, 196 проверок, все зелёные. Старые файлы удалены (архив в /root/).

### CASE
core/case_db.py — доступ к БД. core/case_id.py — генератор LM-YYYYMMDD-NNNN + UUID. web/schema.sql — схема. Сохранение после PDF. Экран /my, карточка /case.

### Фиксы по фидбеку
- Форма сохраняет данные при ошибке
- Все ошибки разом
- Emergency-экран с кнопкой 112
- Единый стиль стоп-страниц
- Нормализация адреса
- Entity check: маркеры угроз
- Промпт модуля 3: «соседи сверху» не путается с квартирой

### Git
Локальный репозиторий. .gitignore исключает .env, cases.db, logs/, _archive/.

## Сигналы от тестеров

95% обращений — про потребителя. Подтверждён приоритет Модуля 1.

## Известные ограничения

- CASE в session — потерял cookie = потерял список
- Нет HTTPS — ждёт домена
- CASE без шифрования (SQLite, права 600)

## История багов

Форма обнуляется — session. Ошибки по одной — список разом. «В квартире № 44» как источник шума — промпт. Потеряно «убивают жильцов» — маркеры. Адрес без запятых — core/address. Счётчик дел больше реального — index(). CSS не грузится — права. Нет топ-бара на стопе — шаблон.
