**Домен:** legalmind.su (ждёт оплаты)

## Что работает

### Модуль 2 — Документы по ЖКХ (181 тип)

От жалобы в УК до иска в суд. **181 тип документа** в 11 категориях:

- **Базовые** — УК, ГЖИ, РПН, прокуратура, ущерб
- **Деньги** — перерасчёт, квитанция, снижение платы, пени, рассрочка, капремонт-взносы
- **Надзорные** — Росжилнадзор, ФАС, МЧС, СЭС, Ростехнадзор, Росприроднадзор
- **Соседи** — затопление, перепланировка, курение, антисанитария, шум
- **Инфраструктура** — детская, мусоропровод, освещение, шлагбаум, кондиционер
- **Ремонт** — подъезд, крыша, фасад, фундамент, сети
- **Безопасность** — вред здоровью, сосульки, люки, электрика, лифты
- **Судебные** — иски, возражения, обжалования
- **Градостроительство** — стройка, снос деревьев, самозахват земли
- **Управление** — тарифы, ОДПУ/ИПУ, смена УК, совет дома
- **Раскрытие информации** — договор, акты, протоколы, счёты

**Авто-детект типа** — юзер пишет «холодные батареи, дома 15 градусов» → система сама выбирает `holodnye_batarei` и подставляет нужные нормы (Пост. 354). Работает через `modules/uk/doc_detect.py` (45 тестов, 100% попаданий).

Нормы: ЖК РФ, Пост. 491, 354, 170, 47, 410, 731, 214-ФЗ и профильные.

### Модуль 3 — Жалоба на шум

Музыка, ремонт, крики, лай собаки, топот, вечеринки.

Нормы: региональные (85 субъектов в `region/data/noise_laws.db`). Регион — гибридно: regex + embeddings.

### Модуль 1 — Потребитель (4 сценария + расширения)

Один движок, четыре конфига, авто-детект сценария по тексту.

| Сценарий | Ст. ЗоЗПП | Покрытие |
|---|---|---|
| Товар с браком (`defect`) | 15, 16, 18, 19, 20, 21, 23, 24 | + отказ в ремонте, + просрочка 45 дней, + ничтожные условия (16), + гарантия vs 2 года (19), + текущая цена (24) |
| Возврат 14 дней (`return14`) | 15, 16, 22, 25 | + невозвратные (Пост. 2463), + техсложные (Пост. 924) |
| Маркетплейс (`marketplace`) | 12, 15, 16, 18, 22, 23.1, 26.1 | + 12 площадок, номер заказа, автоадрес, просрочка доставки, недостоверная инфа (12) |
| Услуга (`service`) | 10, 12, 15, 16, 27, 28, 29, 30, 31, 32, 33 | 4 базовых + 5 спец-подтипов (банк/страх/туризм/образование/медицина) |

**Сквозные нормы для всех сценариев:** ст. 10 (право на информацию), ст. 15 (компенсация морального вреда), ст. 16 (ничтожные условия продавца).

**Дополнительно:**
- **Калькулятор неустойки** — ст. 22, 23 (1%/день), ст. 23.1 (0.5%/день), ст. 28 (3%/день, cap), ст. 20/23 (ремонт >45 дней)
- **Справочник 12 маркетплейсов** (реестр МЭР): Ozon, WB, Яндекс Маркет, Avito, Lamoda, Яндекс Еда/Go/Путешествия, Delivery Club, Магнит Маркет, Купер, Joom — авто-подстановка юрадреса
- **Умная шапка PDF** — ООО/АО/ПАО → «Директору», ИП/самозанятый → как есть, физлицо → «Гражданину/Гражданке», маркетплейс → «Владельцу агрегатора»
- **Расчёт неустойки в PDF и карточке дела** — основное требование + неустойка с формулой + итого + основание
- **Авто-детект подтипов** — LLM выбирает нормы по фактам (срок / смета / отказ / качество / банк / страховка / ремонт / доставка)

## Безопасность

Пройден внешний аудит (13-14.09.2026). Закрыто 10 из 11 пунктов.

### Доступ и данные
- **IDOR** в `/case/<ref>/pdf/<id>` закрыт — фильтр по (doc_id, case_number)
- **SECRET_KEY** обязателен — сервис падает при отсутствии
- **Секреты** — только в `web/.env` и `.env.backup`, оба в `.gitignore`
- **Права на сервере:** `chmod 600` на `.env` и `.env.backup`, владелец `legal:legal`
- **Деплой** через Deploy Key с read-only доступом

### Защита от атак
- **CSRF** — ручной токен в session + `hmac.compare_digest`,
  скрытое поле `_csrf_token` в форме, 400 при провале
- **Rate limiting** — двойной слой:
  - nginx `limit_req` (1 r/m на `/submit`, 5 r/s общий)
  - Python in-memory (50 дел/сутки на IP)
- **ProxyFix** — правильный IP клиента из X-Forwarded-For
- **Логи без ПДн** — длина адреса, не сам адрес

### Cookie и HTTPS
- **Cookie сессии** — HttpOnly, SameSite=Lax, Secure (включается при HTTPS)
- **HTTPS** — ждёт домена legalmind.su

### 152-ФЗ (персональные данные)
- Обязательный чекбокс согласия на обработку ПДн в форме
- Страница `/privacy` с политикой конфиденциальности
- Серверная проверка согласия — без него форма не принимается

### Бэкапы и SQLite
- Ежедневный бэкап `cases.db` в Yandex Object Storage (cron 03:00 UTC)
- **Шифрование бэкапов** — `openssl enc -aes-256-cbc -pbkdf2 -iter 100000`
- **Пароль — в Yandex Lockbox** (REST API, `core/lockbox.py`, IAM-кэш 11 ч)
- **Обёртка `scripts/run_backup.sh`** — cron зовёт её (защита от гонки с деплоем)
- **WAL для SQLite** — `PRAGMA journal_mode=WAL`, `synchronous=NORMAL`
- Retention: 30 дней (ротация автоматическая)
- SQLite `.backup()` — атомарно, безопасно при параллельных читателях
- Инструкция: `docs/BACKUP.md`

### Мониторинг
- **Cloud Function** в Yandex Cloud — дёргает `/health` каждые 5 минут
- **Telegram-алерты** при падении/восстановлении
- **Антифлуд** через S3 (`monitoring/state.json`)
- Инструкция: `deploy/health_check/README.md`

### CI/CD
- Tests на каждый push (2118 проверка + Playwright)
- Deploy через `workflow_run` — только после зелёных Tests
- Smoke против прода по понедельникам
