# Legal Mind

Веб-сервис для физических лиц. Превращает неформальное описание бытовой
проблемы в готовый юридический документ (PDF).

**Работает:** http://201.24.49.121/ (домен `legalmind.su` в планах)

## Что уже работает

Два модуля, каждый — полный конвейер от текста пользователя до PDF.

### Модуль 2 — Жалоба в управляющую компанию

**Типы проблем:** уборка подъезда, отопление, лифт, уборка снега, протечка
крыши, домофон, любые нарушения содержания общего имущества.

**Адресат:** управляющая компания.

**Правовые нормы (универсальные для РФ):**

- Статья 161 Жилищного кодекса РФ — ответственность УК за содержание
- Постановление Правительства РФ от 13.08.2006 № 491 — требования к содержанию
- Постановление Госстроя РФ от 27.09.2003 № 170 — конкретные нормативы

**Тестовых кейсов:** 12 (6 типовых, 3 экстренных, 3 стоп).

### Модуль 3 — Жалоба на нарушение тишины

**Типы проблем:** громкая музыка, ремонт, крики, лай собаки, топот,
вечеринки, скандалы.

**Адресат:** участковый уполномоченный полиции.

**Правовые нормы:** региональные законы субъектов РФ — база из **85 регионов**.

Регион определяется **гибридной системой:**

1. **Регулярки** (26 паттернов на 85 регионов) — быстро, <1 мс.
2. **Эмбеддинги** (Yandex Text Embeddings, 85 векторов с обогащением
   крупными городами) — fallback для нестандартных формулировок.

Если регион не определён — используется нейтральная формулировка без
ссылки на закон.

**Тестовых кейсов:** 12 (6 типовых, 2 экстренных, 4 стоп).

### Модуль 1 — Потребитель (в разработке)

**Приоритет подтверждён людьми:** ~95% обращений — про товары.
Подмодули: A (брак, ст. 18 ЗоЗПП), B (возврат 14 дней, ст. 25),
C (маркетплейс, ст. 26.1), D (услуги, ст. 29).

## Архитектура

```text
Пользователь открывает http://201.24.49.121/
        |
        v
[nginx] reverse proxy + статика -> 127.0.0.1:5000
        |
        v
[Flask] HTML-форма -> валидация полей
        |
        |-- телефон   -> core.phone_check
        |-- ФИО       -> core.name_declension (родительный падеж)
        |-- адрес     -> region.extractor (regex + embeddings)
        |
        v
[Код] Hard-check (modules/*/hardchecks.py):
      - emergency          -> 112
      - не тот модуль      -> стоп
      - нет адреса         -> стоп
      - короткое описание  -> стоп
      - слишком общее      -> стоп
      - соседи             -> стоп (в другой модуль)
        |
        v
[Alice AI Flash] Нормализация: переписать текст официальным языком
      - без ссылок на законы
      - сохранение всех существенных фактов
        |
        v
[Код] Entity recall: проверка, что модель не потеряла факты
      - если потеряла -> один retry с явным указанием
        |
        v
[Код] Для модуля 3: чтение регионального закона из region/data/noise_laws.db
        |
        v
[Код] PDF: fpdf2, документ с шапкой, телом, ПРОШУ, подписью
        |
        v
Пользователь скачивает PDF
```

**Принцип:** если что-то можно проверить кодом — проверяем кодом.
LLM только там, где нужна языковая гибкость.

## Стек

- **Backend:** Python 3.14, Flask
- **Application server:** gunicorn (2 воркера)
- **Web server:** nginx
- **Процесс-менеджер:** systemd
- **PDF:** fpdf2 + Arial/DejaVu
- **Склонение ФИО:** pymorphy3
- **LLM (нормализация):** Alice AI Flash (Responses API Yandex AI Studio)
- **LLM (RAG, разово):** YandexGPT Pro
- **Эмбеддинги:** Yandex Text Embeddings (query + doc)
- **Поиск:** Yandex Search API v2
- **Хостинг:** Timeweb Cloud VPS, Ubuntu 24.04, IP `201.24.49.121`

## Что важно знать

**LLM не выбирает законы из памяти.** Для модуля 2 нормы захардкожены
в коде. Для модуля 3 закон подтягивается из `region/data/noise_laws.db`.

**Офлайн-тесты — ворота перед деплоем.** Пока `python tests\run_all.py`
красный — не заливаем.

**Retry — норма.** Если модель забыла факт, entity check попросит второй раз.

**Дисклеймер обязателен.** Сервис — «просто ПО», не юридическая услуга.
